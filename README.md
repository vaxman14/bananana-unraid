# bananana.dev for Unraid

Community Applications templates for [bananana.dev](https://bananana.dev), built by CTF Designs, LLC.

- **bananana-brain** (`romanvaxman/bananana-brain`): the brain, your own control room for servers, Macs and PCs. Create a free account at https://bananana.dev/start, paste the setup token into the template, and your brain is at your-name.bananana.dev.
- **bananana-node** (`romanvaxman/bananana-node`): the agent that connects this Unraid server to a brain. On the brain, open Nodes › Add node › Install command › Docker and paste the code into the template. It runs privileged with the host's processes, network and name so it can report and manage the server itself.

Both connect out through an end-to-end encrypted relay; no ports are opened.
